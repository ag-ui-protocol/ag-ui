# Source derivation

`Sources/AGUICore`, `Sources/AGUIClient`, and their unit tests are derived from
ag-ui-protocol/ag-ui pull request #1512 at commit
`84c7fbfc51d5c0295ffc0561636f11b7ff70a422`. The original MIT license and
copyright remain in `LICENSE` and source headers. This package intentionally
includes only the core and client libraries; the dojo command and integration
test are local additions.
