# Official A2UI v0.9.1 schemas

Unmodified source files from `a2ui-project/a2ui` commit
`1c45c809b655878d06e3afc6dda22100afecc0a4` (`specification/v0_9_1`).
The Basic Catalog is copied from `catalogs/basic/catalog.json`; other files
are from `json/`. Apache-2.0 license included as `LICENSE`.

These documents deliberately retain their declared v0_9 IDs. The validation
registry maps the server schema's relative `catalog.json` reference to the
selected local catalog, never to an automatically fetched remote resource.
