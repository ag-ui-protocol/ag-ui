# Middleware

An `AGUIMiddleware` sits between your agent and the wire. It receives the run
input and the next stage, and returns the events that continue toward the
client. It can change the input before the agent runs, and it can drop, change
or add events on the way out. This is the .NET counterpart of the TypeScript
SDK's `Middleware`.

Middleware runs on AG-UI events, after `AsAGUIEventStreamAsync` has converted
the `ChatResponseUpdate` stream. The model, function invocation and anything
that stores the chat history still see the complete stream. To work on
`ChatResponseUpdate`s instead, write a `DelegatingChatClient`.

## Build a pipeline

`AsAGUIRunDelegate` turns a chat client into an `AGUIRunDelegate`, a function
that runs one AG-UI run and returns its events. Without middleware, the
endpoint calls it directly:

```csharp
var run = chatClient.AsAGUIRunDelegate(jsonSerializerOptions);

app.MapPost("/agent", ([FromBody] RunAgentInput input, HttpContext httpContext, CancellationToken ct) =>
    AGUIResults.Events(run(input, ct), httpContext, ct));
```

With middleware, register it on an `AGUIMiddlewarePipeline` and build the
pipeline around the same delegate. The endpoint does not change. The first
middleware registered is the outermost: it sees the input first and the events
last.

```csharp
var run = new AGUIMiddlewarePipeline()
    .Use(new AuditMiddleware())
    .Build(chatClient.AsAGUIRunDelegate(jsonSerializerOptions));

app.MapPost("/agent", ([FromBody] RunAgentInput input, HttpContext httpContext, CancellationToken ct) =>
    AGUIResults.Events(run(input, ct), httpContext, ct));
```

The delegate adapts whatever input it receives, so a middleware that rewrites
the input changes what the model sees. When the innermost stage needs more than
the chat client, such as server tools for one endpoint, write it yourself:

```csharp
var run = pipeline.Build((input, ct) =>
{
    var ctx = input.ToChatRequestContext(jsonSerializerOptions);
    ctx.ChatOptions.Tools ??= [];
    ctx.ChatOptions.Tools.Add(searchTool);
    return chatClient.GetStreamingResponseAsync(ctx.Messages, ctx.ChatOptions, ct)
        .AsAGUIEventStreamAsync(ctx, ct);
});
```

The samples' `MapAGUI` helper accepts the pipeline directly:

```csharp
app.MapAGUI("/", middleware => middleware
    .Use(new AuditMiddleware()));
```

## Write a middleware

Derive from `AGUIMiddleware`, or pass a function to `Use`. One instance serves
every run, so keep per-run state in locals of `RunAsync`, not in fields. An
async iterator gets fresh locals for each run.

```csharp
public sealed class RunLoggingMiddleware(ILogger<RunLoggingMiddleware> logger) : AGUIMiddleware
{
    public override async IAsyncEnumerable<BaseEvent> RunAsync(
        RunAgentInput input,
        AGUIRunDelegate next,
        [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        logger.LogInformation("Run {RunId} started with {Count} messages", input.RunId, input.Messages.Count);

        await foreach (var evt in next(input, cancellationToken))
        {
            if (evt is RunErrorEvent error)
            {
                logger.LogWarning("Run {RunId} failed: {Message}", input.RunId, error.Message);
            }

            yield return evt;
        }
    }
}
```

Text arrives as `TEXT_MESSAGE_CONTENT` deltas of a few tokens each, so a
middleware that rewrites text has to buffer across deltas. A pattern can span
two of them.

```csharp
pipeline.Use((input, next, ct) => AddTimestamps(next(input, ct)));
```
