# Rust SDK

This branch proposes a single `ag-ui` crate for the community Rust SDK. Adoption
and publishing are still subject to the upstream team's decision. The old
`ag-ui-core` and `ag-ui-client` source has been removed from this proposed tree;
their existing published versions remain available.

| Feature | Capability |
| --- | --- |
| Core types | Events, IDs, messages, run input and serialization |
| `server` | Agent hosting and event emission |
| `client` / `http` | Conversation state and HTTP/SSE consumption |
| `axum` | Axum routing for a hosted agent |
| `verify` | Ordering/attribution checks, including standalone `server::EventVerifier` when `server` is enabled |

Use the [migration proposal](/sdk/rust/migration-proposal) to try the candidate
from a checkout and compare APIs. Installing a published standalone `ag-ui` version
does not select this branch or imply upstream adoption.

The [transition and versioning proposal](/sdk/rust/transition) describes the
decisions still needed with the team and existing maintainers. The feature-based
layout does not require acquiring a separate `ag-ui-server` package name.

## Legacy package documentation

The [legacy core](/sdk/rust/core/overview) and [legacy client](/sdk/rust/client/overview)
pages are retained for users of the published 0.1.0 packages. They do not describe
the new `ag-ui` API. Final legacy releases should preserve existing behavior and
link to migration guidance; those releases are not performed by this proposal.
