# Rust SDK

A feature-based `ag-ui` implementation is proposed alongside these existing
packages. See the [migration proposal](/sdk/rust/migration-proposal) to review it.
The existing package source and APIs remain in place; adoption and any later
source removal are still subject to agreement.

The Rust SDK consists of two crates:

- ag-ui-core: shared types and events
- ag-ui-client: client utilities and concrete agents like HttpAgent

## Getting started

```bash
# Core data types and events
cargo add ag-ui-core

# Client crate with Agent trait, HttpAgent, subscribers
cargo add ag-ui-client
```
