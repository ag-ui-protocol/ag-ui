# Events

`ag_ui_core::event::Event<StateT>` is the tagged stream event enum. Its 31 AG-UI
1.0 variants are listed below; each has a corresponding `EventType` value and a
typed event struct. Common optional fields on `BaseEvent` include `timestamp`,
`rawEvent`, `metadata`, and `subagentRunId`.

| Group              | Event variants                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Run and step       | `RunStarted`, `RunFinished`, `RunError`, `StepStarted`, `StepFinished`                                                                                          |
| Text               | `TextMessageStart`, `TextMessageContent`, `TextMessageEnd`, `TextMessageChunk`                                                                                  |
| Tool calls         | `ToolCallStart`, `ToolCallArgs`, `ToolCallEnd`, `ToolCallChunk`, `ToolCallResult`                                                                               |
| State and messages | `StateSnapshot`, `StateDelta`, `MessagesSnapshot`                                                                                                               |
| Activity           | `ActivitySnapshot`, `ActivityDelta`                                                                                                                             |
| Reasoning          | `ReasoningStart`, `ReasoningMessageStart`, `ReasoningMessageContent`, `ReasoningMessageEnd`, `ReasoningMessageChunk`, `ReasoningEnd`, `ReasoningEncryptedValue` |
| Subagents          | `SubagentStarted`, `SubagentFinished`, `SubagentError`                                                                                                          |
| Passthrough        | `Raw`, `Custom`                                                                                                                                                 |

`StateSnapshot<StateT>` replaces the state; `StateDelta` carries typed
`JsonPatchOperation` values (RFC 6902). `MessagesSnapshot` supplies a message
list; the client reconciles by ID and preserves locally streamed activity or
reasoning messages when the snapshot does not declare those roles. Chunk events
combine optional start, delta, and end data; `Agent::run_input` and
`Agent::run_agent` expand chunks into start/content-or-args/end events before
delivering callbacks. `Agent::run` retains the raw wire variants.

`RunFinished` can carry `result`, `outcome`, and `usage`. `RunError` can carry
`usage`. `outcome` is `RunFinishedOutcome::Success { pending_tool_call_ids }`,
`Interrupt { interrupts }`, or `Cancelled`. `TokenUsage` includes provider,
model, input, output, total, reasoning, cached input, and cache write input
token counts. An interrupt has an ID and reason, with optional message, tool
call ID, response schema, expiry, metadata, and subagent run ID. Resume with
`RunAgentParams::with_resume` and `ResumeEntry` values.

The core representation retains legacy `Thinking*` variants for compatibility.
The compatibility boundary translates them before current-1.0 normalization
and emits diagnostics available through `HttpAgentBuilder::with_diagnostic_handler`.
Current producers should emit `REASONING_*` events directly.

Implement `AgentSubscriber::on_event` for all events, or a typed `on_*_event`
callback for a specific variant. See
[AgentSubscriber](/sdk/rust/client/subscriber).

Public protocol enums are non-exhaustive. External matches must include a
wildcard branch for future variants. Public event structs remain constructible
with literals, so future field additions can still require breaking releases.
